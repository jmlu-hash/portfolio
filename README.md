# 设计作品集

海报 / 证照 / 展板文化墙 作品归档与在线展示。

## 目录

- `posters/` 海报
- `badges/` 证照 / 工作证
- `walls/` 展板 / 文化墙

## 在线预览

GitHub 仓库 → Settings → Pages → Source 选 `main` / `root` → 保存。
访问 `https://jmlu-hash.github.io/portfolio/`。

## 上传作品

把 PNG / SVG 作品放进对应目录，刷新 Pages 即可显示。图片命名建议：`类别-主题-年份.png`，如 `海报-普查工作证-2026.png`。
